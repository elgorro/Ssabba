# Ssabba

Ssabba is a self-hostable tracker for beach volleyball: players, teams, matches, sets and the ladder
that follows from them.

This wiki is built with [Hugo](https://gohugo.io/) from the `docs/` folder of the repository and served
by the same stack as the app, under `/docs`.
